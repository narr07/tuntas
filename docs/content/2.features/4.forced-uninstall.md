title: Forced Uninstall
description: Clean up a program whose uninstaller is broken or already gone.

  icon: i-lucide-shield-alert

Sometimes a program's uninstaller is missing, crashes or refuses to run. **Forced Uninstall** skips the uninstaller and goes straight to the leftover scan.

Either pick a program from the list, or type:

- **Program name**: the name as it appeared in the program list.
- **Publisher** (optional): lets Tuntas look inside the publisher's folders.
- **Installation folder** (optional): the folder the program lived in.

Tuntas refuses an installation folder that is protected, such as a drive root, `C:\Program Files` itself or your user folder. See [How Tuntas protects you](/safety/how-tuntas-protects-you).

The results use the same [match badges](/features/leftovers#match-badges) and the same Recycle Bin and registry backups as a normal uninstall.
