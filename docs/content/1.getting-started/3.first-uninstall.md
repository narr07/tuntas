::steps{level="3"}

### Pick the program

Open **Installed Programs** and click the program. Search by name, publisher or folder if the list is long. The panel on the right shows its install folder, registry key and size.

### Start the uninstaller

Click **Uninstall**. If the program offers a quiet mode, you can choose it to skip the uninstaller's wizard.

In the confirmation dialog you can tick **Create a System Restore point first** (this needs administrator rights). Windows makes at most one restore point a day, so if one was made recently it simply skips this step.

### Let it finish

The program's own uninstaller opens. Go through it as usual. Tuntas waits until it and any helper it started have closed.

If the program is still registered afterwards, for example because you clicked Cancel, Tuntas tells you so and stops. Nothing is deleted.

### Review the leftovers

Tuntas lists what it found. Items that clearly belong to the program are already ticked. Items marked with a warning badge were matched by name only, so look at them before ticking them. See [Leftovers](/features/leftovers) for what each badge means.

### Delete

Click **Delete selected** and confirm. Files go to the Recycle Bin. Registry keys are exported to a `.reg` file first; the result banner has a button to open that backup folder.

If a file is still in use, Tuntas tells you which program holds it. See [Files in use](/features/files-in-use).

::
