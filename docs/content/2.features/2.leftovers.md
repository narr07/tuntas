## Where Tuntas looks

- The program's registered install folder.
- `AppData\Local`, `AppData\Local\Programs`, `AppData\Roaming` and `AppData\LocalLow`.
- `ProgramData`, `Program Files` and `Program Files (x86)`.
- The Start Menu, for your account and for all users.
- The registry: `HKCU\SOFTWARE`, `HKLM\SOFTWARE` and `HKLM\SOFTWARE\WOW6432Node`, plus the program's own uninstall entry.

## How a match is decided

Tuntas first cleans up the program name: version numbers, architecture tags and anything in brackets are dropped. `7-Zip 23.01 (x64)` becomes `7-Zip`, and `Mozilla Firefox (x64 en-US)` becomes `Mozilla Firefox`.

A folder or key then matches only when its name **is** that name. A folder named `Microsoft` does not match "Microsoft Teams" just because the words overlap. Inside a publisher's folder, the program's own name is enough: `AppData\Roaming\Mozilla\Firefox` matches Firefox from publisher Mozilla.

Folders shared by many programs, such as `Microsoft`, `Google`, `Programs`, `Packages` or `Temp`, are never matched directly.

## Match badges

| Badge | Meaning | Ticked for you |
| --- | --- | --- |
| **Exact path** | The registered install folder (it holds the uninstaller or is named after the program), or the program's own uninstall entry | Yes |
| **Same name** | A folder, shortcut or registry key whose name equals the program name | Folders and shortcuts yes, registry keys no |
| **Publisher folder** | `Publisher\Program` inside one of the places above | Folders yes, registry keys no |
| **Registered path, verify** | The registered install folder, but its name does not look like the program's. Some programs register a shared folder such as `D:\Games` | No |

Anything with a warning badge needs a second look before you tick it.
