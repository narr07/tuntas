---
title: Hunter Mode
description: Find out which installed program a running process belongs to.
navigation:
  icon: i-lucide-crosshair
---

**Hunter Mode** lists running processes with their memory use and file path. When a process belongs to an installed program, the program's name is shown next to it.

From there you can:

- open the process's folder in Explorer,
- jump to **Forced Uninstall** with the program already filled in,
- **Close** the process. Tuntas first asks it to close normally and only ends it if it does not respond within a few seconds.

Windows system processes cannot be closed from Tuntas.
