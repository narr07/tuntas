When you remove a program through Windows Settings, Windows runs the uninstaller that came with the program and trusts it to clean up. Many do not. Settings folders stay in AppData, shortcuts stay in the Start Menu, and registry keys stay forever.

Tuntas runs that same uninstaller and then finishes the job:

1. **It waits for the uninstaller to really finish.** Many uninstallers start a hidden copy of themselves and exit straight away. Tuntas follows that copy too.
2. **It checks the program is gone.** If you cancelled the uninstaller, or it failed, Tuntas stops there and deletes nothing.
3. **It looks for leftovers.** Folders, shortcuts and registry keys that carry the program's exact name.
4. **You choose what goes.** Only items that clearly belong to the program are ticked. Everything else waits for you to check it.
5. **It can all be undone.** Files go to the Recycle Bin and registry keys are backed up first.
