The **Windows Apps** page lists Microsoft Store apps (also called UWP or Appx packages) installed for your account. Frameworks and runtimes that other apps depend on are hidden.

Apps that Windows itself marks as non-removable, or that are signed as part of Windows, show a **Protected** badge and cannot be removed. Everything else can be removed with **Remove**, which uses the same `Remove-AppxPackage` command Windows uses.

::tip
A removed Store app can be installed again from the Microsoft Store at any time.
::
