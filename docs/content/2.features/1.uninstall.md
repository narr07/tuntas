The **Installed Programs** page lists everything registered in the three places Windows keeps uninstall information: 64-bit programs, 32-bit programs and programs installed only for your account. Updates and hotfixes are hidden, because they belong to their parent product.

## How Tuntas runs an uninstaller

Each program registers an uninstall command. Tuntas starts it the way Windows does, so quoted paths, unquoted paths with spaces and `%VARIABLES%` all work.

Two details make Tuntas more reliable than a plain launcher:

- **MSI products.** Many register `MsiExec.exe /I{...}`, which opens the repair wizard instead of removing anything. Tuntas changes it to `/X{...}`, the uninstall switch. In quiet mode it adds `/qb /norestart`.
- **Uninstallers that hand over.** Inno Setup, NSIS and others copy themselves to `%TEMP%`, start the copy and exit at once. Tuntas follows every process the uninstaller starts and only continues when all of them are done. Browsers or Explorer windows that an uninstaller opens at the end (a "sorry to see you go" page, for example) are not waited for.

When it is done, Tuntas checks whether the program's uninstall entry is gone. If it is still there, the uninstall did not happen, and Tuntas does not scan or delete anything.

## Uninstalling several programs

Tick programs in the list and click **Uninstall**. They are removed one after another, in quiet mode where possible. You can stop after the current one at any time.

Because nobody is watching each step, batch mode is stricter: it only removes leftovers marked **Exact path** (the program's own install folder and uninstall entry). Name matches are left for you to review later.
