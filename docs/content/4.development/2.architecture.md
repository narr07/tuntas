Tuntas is a [Tauri 2](https://tauri.app) app. The interface is a [Nuxt 4](https://nuxt.com) single-page app built with [Nuxt UI](https://ui.nuxt.com); everything that touches Windows is written in Rust.

```text
app/
  composables/useUninstallerBackend.ts  the only place that calls Rust
  components/                           Nuxt UI based building blocks
  pages/                                one page per sidebar entry
src-tauri/src/
  commands.rs                           Tauri commands (all run off the UI thread)
  safety.rs                             the deletion guard
  win.rs                                Win32 wrappers; all unsafe code lives here
```

Some principles the code follows:

- **The UI never builds system commands.** It sends data (an item, a category id) and the Rust side decides what to run.
- **Every filesystem delete goes through `check_deletable`** in `safety.rs`.
- **The window has no file system or shell permissions.** Its Tauri capability only allows the app's own commands.
- **No console windows.** Every helper process is started with `CREATE_NO_WINDOW`.
