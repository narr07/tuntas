## Requirements

- Windows 10 or 11
- [Bun](https://bun.sh) 1.3 or newer
- [Rust](https://rustup.rs) (stable, MSVC toolchain)
- Microsoft C++ Build Tools ("Desktop development with C++")

## Run it

```bash [Terminal]
git clone https://github.com/narr07/tuntas.git
cd tuntas
bun install
bun run desktop:dev
```

To test machine-wide features, start the terminal as administrator, or use **Restart as administrator** inside the app.

## Checks

```bash [Terminal]
bun run lint
bun run typecheck
bun run test:rust
```

## Build an installer

```bash [Terminal]
bun run desktop:build
```

The installers end up in `src-tauri/target/release/bundle/nsis` and `src-tauri/target/release/bundle/msi`.

## Releases

Pushing a tag such as `v0.1.0` starts the release workflow, which builds both installers on GitHub Actions and attaches them to a GitHub release. The download button on this site picks up the newest release on its own.
