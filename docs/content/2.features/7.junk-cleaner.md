The **Junk Files** page measures and clears:

| Category | Location |
| --- | --- |
| Temporary files | `%TEMP%` |
| Windows temporary files | `C:\Windows\Temp` (needs administrator rights) |
| Windows error reports | `ProgramData\Microsoft\Windows\WER` |
| Application crash dumps | `AppData\Local\CrashDumps` |
| Installer staging | `AppData\Local\SquirrelTemp` |
| Edge, Chrome and Brave caches | The cache folders of every browser profile |

Files are deleted one by one, permanently; the folders themselves stay. A file another program has open is skipped, and the result tells you how many were skipped. That makes it safe to clean while you work.

If a browser is running, its row says so. Close the browser for a complete clean.

::note
Tuntas does not empty the Windows **Prefetch** folder. Windows uses it to start programs faster, so clearing it slows the next boot down.
::
