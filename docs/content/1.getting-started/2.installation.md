## Download

:download-card

Tuntas runs on Windows 10 and Windows 11 (64-bit). It needs the Microsoft Edge WebView2 runtime, which is already part of Windows 11 and of every up-to-date Windows 10. The installer adds it if it is missing.

Pick the **.exe** installer unless your organisation deploys software with MSI packages.

## "Windows protected your PC"

Tuntas is not code-signed yet. Code signing certificates cost money every year, and a new open-source project usually starts without one. Until then, Microsoft Defender SmartScreen shows a warning for the installer:

1. Click **More info**.
2. Check that the app name is the installer you downloaded from this site or from the [GitHub releases page](https://github.com/narr07/tuntas/releases).
3. Click **Run anyway**.

::tip
Every release is built by GitHub Actions straight from the public source code. You can read the [release workflow](https://github.com/narr07/tuntas/blob/main/.github/workflows/release.yml) to see exactly how the installer is made.
::

## Administrator rights

Tuntas starts as a normal user. That is enough to remove programs installed for your account, clean your own temporary files and manage your own startup items.

For anything machine-wide you need administrator rights: programs installed for all users, the `HKLM` registry, `C:\Windows\Temp`, startup items for all users, restore points and deleting files at restart. When Tuntas runs without them, the sidebar shows **Limited mode** with a **Restart as administrator** button.
