## Files and folders

Leftover files and folders go to the **Recycle Bin**. Open it, right-click the item and choose **Restore**.

::note
Windows deletes items that are too large for the Recycle Bin permanently. You can change the Recycle Bin's size in its properties.
::

The Junk Files cleaner is the exception: temporary files and caches are deleted permanently, because programs recreate them anyway.

## Registry keys

Before deleting a registry key, Tuntas exports it to a `.reg` file in:

```text
%LOCALAPPDATA%\Tuntas\Backups\<date>-<time>\
```

Use **Open registry backup** in the result banner to go there. Double-click a `.reg` file and confirm to put the key back.

## The whole system

If you ticked **Create a System Restore point first**, open the Start menu, search for **Create a restore point**, click **System Restore** and pick the point named *Before removing …*.
